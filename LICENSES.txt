FJORD DEFENCE — licences and credits

GAME CODE
  Written for this project. Plain JavaScript, Canvas 2D, no third party libraries,
  no frameworks, no bundler.

ART
  All sprites, level backgrounds, road layers, UI icons, the title screen and the
  store icon were produced for this project and are not derived from any existing
  game, film or published artwork.

AUDIO
  There are no audio files in this build. Every sound effect and the ambient wind
  are synthesised at runtime with the Web Audio API, so no samples are used.

FONTS
  The build uses the system font stack (Trebuchet MS, Segoe UI, system-ui).
  Bundled font files in assets/fonts, if present, are:
    Lato   — SIL Open Font License 1.1 — https://github.com/latofonts/lato-source
    Inter  — SIL Open Font License 1.1 — https://github.com/rsms/inter
  The SIL OFL permits use, modification and redistribution, including commercial
  use, as long as the fonts are not sold on their own and the licence travels with
  the files.

THIRD PARTY SERVICES
  The YouTube Playables SDK (https://www.youtube.com/game_api/v1) is loaded only
  when the game runs inside a frame on YouTube. On any other host the game makes
  no network requests at all.
